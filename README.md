# CI/CD Python API Deployment 🚀 (Active Development)

**Note:** This project is currently under active development. 

## Overview
This project demonstrates a complete, automated deployment pipeline for a Python-based web application. It features a lightweight API built with Object-Oriented Programming (OOP) principles using FastAPI. The repository is integrated with GitHub Actions to automatically trigger testing and deployment workflows upon every push, ensuring continuous delivery to an AWS Linux environment.

## Tech Stack
* **Language:** Python 3.x (Object-Oriented Design)
* **Framework:** FastAPI
* **Testing:** pytest
* **CI/CD:** GitHub Actions
* **Infrastructure:** AWS EC2 (Linux)

## Key Features
* **OOP Architecture:** Clean, modular code structured using Python classes.
* **Automated Testing:** Unit tests validate data processing and API responses.
* **Continuous Integration:** GitHub Actions automatically provisions a Python environment and runs the `pytest` suite on every commit.
* **Continuous Delivery:** Automated deployment of successful builds to a remote AWS Linux instance.
